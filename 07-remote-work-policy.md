# Remote Work and BYOD Policy

**Document ID:** ISP-007  
**Version:** 1.0  
**Effective Date:** [Date]  
**Owner:** [CISO]

## 1. Purpose

To define security requirements for remote work and the use of personal devices (BYOD) when accessing company resources.

## 2. Key Requirements

2.1 Remote access must use company-approved VPN or zero-trust access solutions with MFA.

2.2 Company data must not be stored on personal devices unless explicitly approved and protected by company MDM / containerization solutions.

2.3 Devices used for work (company-owned or personal) must:
- Have up-to-date operating system and security patches
- Run current antivirus / endpoint protection
- Be protected by a strong screen lock
- Not be jailbroken / rooted

2.4 Public / untrusted networks should be avoided or used only with VPN.

2.5 Lost or stolen devices must be reported immediately.
